# 📊 Sales Analytics: Аналіз поведінки користувачів та продажів e-commerce платформи

Комплексний аналіз даних інтернет-магазину на основі сесій користувачів, замовлень та акаунтів. Проєкт охоплює вивантаження даних із **Google BigQuery**, очищення, дослідницький аналіз (EDA), а також **статистичний аналіз взаємозв'язків та відмінностей між групами** (кореляції, тести гіпотез).

## 📁 Про дані

Дані вивантажені SQL-запитом з BigQuery-датасету `data-analytics-mate` (таблиці `session`, `session_params`, `order`, `product`, `account_session`, `account`) і об'єднані в єдиний датафрейм.

**Характеристики датасету:**
| Параметр | Значення |
|---|---|
| Кількість колонок | 18 |
| Числові колонки | 5 (`ga_session_id`, `account_id`, `is_verified`, `is_unsubscribed`, `price`) |
| Категоріальні колонки | 12 (`continent`, `country`, `device`, `browser`, `mobile_model_name`, `operating_system`, `language`, `medium`, `channel`, `category`, `name`, `short_description`) |
| Колонки дата/час | 1 (`date`) |
| Унікальних сесій | 33 538 |
| Період даних | 01.11.2020 – 27.01.2021 |
| Дублікати | відсутні |

## 🛠 Технології

- **Google BigQuery** (`google-cloud-bigquery`) — вивантаження даних SQL-запитом
- **pandas, numpy** — обробка та агрегація даних
- **matplotlib, seaborn** — візуалізація, у т.ч. `pairplot`, `histplot`
- **scipy.stats** — Pearson, Spearman, Shapiro-Wilk, Mann-Whitney U, Kruskal-Wallis
- **statsmodels** — z-тест для порівняння часток
- **Tableau** — інтерактивний дашборд
- Google Colab / Jupyter Notebook

## 🔍 Етапи аналізу

1. **Вивантаження даних** з BigQuery через SQL-запит з об'єднанням 6 таблиць.
2. **Очищення даних:**
   - `language` (32.7% пропусків) → заповнено `"unknown"`;
   - `account_id`, `is_verified`, `is_unsubscribed` (91.7% пропусків — переважна більшість сесій без реєстрації);
   - `category`, `name`, `price`, `short_description` (90.4% пропусків — купівлею завершується лише невелика частка сесій); категоріальні поля заповнено `"unknown"`, `price` залишено без змін, щоб не спотворити розрахунки.
   - Перевірка дублікатів (не виявлено).
3. **Аналіз користувачів:** топ країн за кількістю зареєстрованих клієнтів, частка підтверджених email, частка відписок, порівняння середнього чека та повторних покупок підписаних/непідписаних користувачів.
4. **Аналіз динаміки продажів** у часі — загалом, у розрізі континентів, каналів трафіку та типів пристроїв.
5. **Зведені таблиці (pivot tables):** кількість сесій за каналами та пристроями; топ-10 категорій товарів у топ-5 країнах; продажі за континентами й каналами.
6. **Статистичний аналіз взаємозв'язків:** кореляції Пірсона та Спірмена між ключовими метриками.
7. **Статистичний аналіз відмінностей між групами:** перевірка гіпотез (Shapiro-Wilk, Mann-Whitney U, Kruskal-Wallis, z-тест часток).
8. **Візуалізація в Tableau** — інтерактивний дашборд з ключовими метриками.

## 💡 Ключові інсайти

**Динаміка продажів:**
- Виявлено виражену **тижневу сезонність** — піки й спади повторюються приблизно кожні 7 днів.
- Аномальні сплеск продажів у **святковий період** (перша половина грудня — перший тиждень січня).
- **Americas** — найприбутковіший, але й найволатильніший континент (пік ≈ 360 000 $); **Asia** стабільніша; **Europe** має найнижчий рівень продажів.

**Канали трафіку:**
- **Organic Search** — головне джерело продажів (щоденно 90–180 тис. $, пік ≈ 270 тис. $).
- **Paid Search** — друге місце (80–150 тис. $, пік ≈ 200 тис. $).
- **Direct** — стабільний канал (60–120 тис. $).
- **Social Search** — найменший внесок (15–40 тис. $).

**Користувачі:**
- Переважна більшість сесій — від **незареєстрованих** користувачів.
- **71.5%** зареєстрованих користувачів підтвердили email; **16.1%** відписалися від розсилки.
- Продажі майже порівну розподілені між **desktop** та **mobile**.

## 📈 Результати статистичного аналізу

| Перевірка | Метод | Результат |
|---|---|---|
| Кількість сесій ↔ продажі за датою | Кореляція Пірсона | r ≈ 0.964, p < 0.05 — сильний прямий зв'язок |
| Продажі: Americas ↔ Asia ↔ Europe | Кореляція Спірмена | 0.61–0.67, p < 0.05 — помірно сильний зв'язок, синхронізація ринків |
| Продажі: підписані ↔ незареєстровані | Кореляція Спірмена | 0.077, p = 0.47 — зв'язку не виявлено |
| Продажі за пристроями (desktop/mobile/tablet) | Кореляція Спірмена | desktop-mobile: 0.77 (сильний); tablet-related: 0.39–0.40 (помірний), усі p < 0.05 |
| Продажі: підписані vs непідписані | Mann-Whitney U | статистично значуща різниця, велика величина ефекту (RBC = 0.968) |
| Частка Organic Search: Europe vs Americas | Z-тест часток | p = 0.46 — різниці не виявлено |
| Кількість сесій за каналами трафіку | Kruskal-Wallis | p ≈ 8.74×10⁻⁵³ — статистично значуща різниця |

## 📌 Рекомендації

- Продовжувати інвестувати в **SEO**, оскільки Organic Search приносить найбільшу виручку.
- Проаналізувати ефективність **Paid Search** і оцінити потенціал масштабування.
- Дослідити причини низької частки **Social Search** та доцільність подальших інвестицій.
- Окремо проаналізувати **грудневий період** пікового попиту для планування майбутніх кампаній.
- Стимулювати **реєстрацію користувачів** — зростання частки зареєстрованих клієнтів.
- Забезпечити якісну **крос-платформну оптимізацію** (desktop/mobile).
